- 所有路由端点通过 `Depends(get_db)`、`Depends(current_user_id)`、`Depends(current_lang)` 注入数据库会话、用户 ID 和语言偏好，保持 handler 层无状态。
- Pydantic schema 统一设置 `model_config = {"from_attributes": True}` 以便直接从 SQLAlchemy ORM 对象序列化为 JSON。
- LLM 调用统一通过 `services/llm.py` 的 `chat()` / `chat_stream()` 底层函数发起，prompt 中通过 `_lang_system(lang)` 注入系统提示以约束输出语言。
- 数据库迁移使用 `try/except` 包裹 `ALTER TABLE ADD COLUMN` 语句，忽略已存在列的错误以实现幂等迁移。
- 安全校验集中在 `security.py`：用户 ID 通过正则 `^[a-zA-Z0-9_-]{1,64}$` 校验，动态 SQL 表名通过 `validate_table_name()` 白名单过滤。
- 处理管线对 LLM 异常采用回滚策略：捕获异常后将记录状态恢复为 `unprocessed` 并重新抛出，保证数据一致性。
