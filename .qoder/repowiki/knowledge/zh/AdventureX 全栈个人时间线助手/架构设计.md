根目录作为双端项目的聚合层：frontend/（Vue 3 + Vite + TypeScript）与 backend/（FastAPI + SQLAlchemy/SQLite）各自独立开发，前端 npm dev 自动代理到后端 :8000；两者通过 RELAY_BASE_URL / ASR_RELAY_WS_URL 指向同一 Cloudflare Worker 中继完成 DeepSeek 对话与 Qwen3-ASR 流式语音转发，生产环境由 Nginx 反向代理 + Systemd 托管。deploy.sh 是跨子模块的统一构建与部署入口，先执行 frontend 的 vite build 产出静态资源到 deploy/static，再打包 backend 代码并替换中继域名、注入 CA 证书、生成 .env，最后 rsync + ssh 远端安装 systemd 服务 lumen.service，实现前后端一体化上线。
