模块以 `main.ts` 为唯一入口，通过 `createApp(App).use(router).use(i18n).mount('#app')` 链式挂载 Vue 应用；在挂载前 import 副作用模块 `install.ts`，确保 `beforeinstallprompt` 事件在页面加载早期被捕获。`App.vue` 仅作为布局壳渲染 `AppLayout` 组件。`install.ts`、`sync.ts`、`user.ts` 均为副作用模块——通过顶层 import 触发执行，各自暴露响应式状态（如 `hintMode`、`syncConnected`）供组件订阅，模块间依赖方向单向：`sync.ts` 依赖 `user.ts` 获取用户 ID，其余互不依赖。`env.d.ts` 声明 Vite 客户端类型及 `.vue` 模块类型，`style.css` 通过 Tailwind CSS v4 的 `@import "tailwindcss"` 引入全局样式。Service Worker 在 `main.ts` 中直接注册 `/sw.js` 并通过 `controllerchange` 事件实现自动刷新。
