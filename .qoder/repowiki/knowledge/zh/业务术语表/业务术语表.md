### 拾光 · Lumen
- 定义：项目名称，"拾光"意为拾起碎片的光，谐音"时光"；Lumen 是拉丁语"光"的意思，也是国际标准光通量单位。产品定位为个人生活助手，帮助用户整理散落的日常记录。
- 别名：Lumen、LMN、拾光

### 三条主线
- 定义：产品的核心功能架构，包括：我做了什么？（时间线 - X轴）、我正在做什么？（当前状态 - Y轴）、我要做什么？（待办 - Z轴）。这是用户组织和管理日常事务的三个主要维度。
- 别名：X/Y/Z 轴、三轴架构

### 情绪指数
- 定义：系统通过分析用户的语音波形（声学特征）和文字内容（语义分析），融合两者给出情绪评分。当文字表面说"没事"但语气疲惫时，系统会记录这种偏离，冲突时倾向于相信声音而非文字。
- 别名：情绪评分、情感分析

### 模糊去重合并
- 定义：系统使用 Levenshtein 算法匹配 + LLM 语义理解的双重机制来识别相似的任务或事件，避免同一件事被重复登记。中等相似度时会询问用户是否要合并。
- 别名：去重、合并、相似度匹配

### 随记润色
- 定义：用户在语音输入后，系统会通过 LLM 隐式修正同音字和表达，使记录更加准确流畅。这是一个后台处理过程，不阻塞用户继续记录。
- 别名：ASR 润色、文本优化

### PWA 安装
- 定义：Progressive Web App 技术，允许用户将应用添加到手机或桌面主屏幕，以独立窗口运行，体验接近原生应用。支持离线使用和推送通知。
- 别名：渐进式 Web 应用、主屏安装

### 多端同步
- 定义：基于 WebSocket 的实时数据同步机制，同一用户 ID 的多个设备间数据变更秒级推送刷新。断线时自动重连，离线状态下降级为轮询模式。
- 别名：实时同步、WebSocket 同步

### API 限流
- 定义：滑动窗口算法实现的请求频率限制，按用户 + 端点进行限流。AI 端点 5-20次/分钟，写入操作 20-30次/分钟，读取操作 120次/分钟，防止 Token 盗刷。
- 别名：速率限制、流量控制
