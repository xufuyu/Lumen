以 `src/main.ts` 为唯一入口，使用 `createApp(App)` 挂载根实例并统一注册 `router` 与 `i18n`；`src/App.vue` 作为顶层布局容器，`src/views/` 按功能划分页面（Dashboard/Home/Query/Tasks/Timeline），`src/components/` 提供可复用 UI 块（MoodCard、TaskCard、TimelineCard、RecordInput、VoiceRecordButton 等）。跨模块通信通过 `src/api/client.ts` 调用后端 REST API，`src/sync.ts` 负责 WebSocket 多端同步，`src/user.ts` 管理用户 ID 持久化，`src/install.ts` 处理 PWA 安装提示。路由定义在 `src/router/index.ts`，国际化资源位于 `src/i18n/locales/{en,zh-CN}.ts`。构建由 Vite 驱动，TypeScript 通过 `vue-tsc -b` 校验后打包。
