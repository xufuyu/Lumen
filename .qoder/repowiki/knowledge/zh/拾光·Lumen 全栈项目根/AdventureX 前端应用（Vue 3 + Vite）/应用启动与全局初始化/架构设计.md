模块以 `main.ts` 为唯一入口，通过 `createApp(App)` 挂载 Vue 应用并链式 `.use(router).use(i18n)` 注入路由与 i18n；`install.ts`、`sync.ts`、`user.ts` 作为副作用模块在启动时 import 即执行，分别承担 PWA 安装提示、WebSocket 实时同步、用户标识持久化的职责。`App.vue` 仅作为布局壳，直接渲染 `AppLayout` 组件。`env.d.ts` 声明 Vite 客户端类型及 `.vue` 模块类型，`style.css` 通过 Tailwind CSS v4 的 `@import "tailwindcss"` 引入全局样式。依赖方向单向：`sync.ts` 依赖 `user.ts` 获取用户 ID，其余模块互不依赖，均被 `main.ts` 或 `App.vue` 消费。
