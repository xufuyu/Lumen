根目录作为双端项目的聚合层：frontend/ 与 backend/ 各自独立开发（前端 npm dev 代理到后端 8000 端口，后端提供 REST + /api/ws/sync WebSocket），两者通过 RELAY_BASE_URL / ASR_RELAY_WS_URL 指向同一 Cloudflare Worker 中继完成 LLM 对话与 ASR 流式语音转发；deploy.sh 是跨子模块的统一构建与部署入口，先执行 frontend 的 vite build 产出静态资源到 deploy/static，再打包 backend 代码并替换中继域名、注入 CA 证书、生成 .env，最后 rsync + ssh 远端安装 systemd 服务 lumen.service，实现前后端一体化上线。
