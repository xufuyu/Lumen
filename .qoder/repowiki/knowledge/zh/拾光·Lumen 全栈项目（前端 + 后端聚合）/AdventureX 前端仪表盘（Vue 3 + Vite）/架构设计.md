以 `src/main.ts` 为唯一入口创建 Vue 根实例，集中注册 `router`、`i18n`、PWA 安装提示（`install.ts`）、WebSocket 多端同步（`sync.ts`）与用户状态持久化（`user.ts`）；`src/App.vue` 作为顶层布局容器，`src/views/` 按功能划分页面（Dashboard/Home/Tasks/Timeline），`src/components/` 提供可复用 UI 块（MoodCard、TaskCard、TimelineCard、RecordInput、VoiceRecordButton 等）。跨模块通信通过 `src/api/client.ts` 统一封装后端 REST 调用，`src/sync.ts` 负责 WebSocket 双向同步，`src/user.ts` 管理用户 ID 持久化，`src/install.ts` 处理 PWA 安装流程。路由定义在 `src/router/index.ts`，国际化资源位于 `src/i18n/locales/{en,zh-CN}.ts`，构建由 Vite 驱动并通过 `vue-tsc -b` 进行类型检查。Service Worker 在 `public/sw.js` 实现离线缓存与自动更新。
