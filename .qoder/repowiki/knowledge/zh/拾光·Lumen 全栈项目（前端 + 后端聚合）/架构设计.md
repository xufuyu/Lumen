根目录作为双端项目的聚合层：frontend/ 与 backend/ 各自独立开发，本地通过 Vite 代理将 API 请求转发至后端 :8000；两者共同依赖 Cloudflare Worker 中继（RELAY_BASE_URL / ASR_RELAY_WS_URL）完成 DeepSeek 对话与 Qwen3-ASR 语音转写，生产环境由 Nginx 反向代理 + Systemd 托管。deploy.sh 是跨子模块的统一发布入口，先执行前端 vite build 产出静态资源到 deploy/static，再打包后端代码、替换中继域名、注入 CA 证书并生成 .env，最后 rsync + ssh 远端安装 systemd 服务 lumen.service，实现前后端一体化上线。
