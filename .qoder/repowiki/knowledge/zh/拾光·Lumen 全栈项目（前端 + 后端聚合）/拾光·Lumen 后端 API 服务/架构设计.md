模块采用典型的 FastAPI 分层架构：
- 入口 `main.py` 通过 `lifespan` 钩子初始化 SQLite 数据库并挂载 `SecurityMiddleware`、CORS 中间件，集中 `include_router` 注册所有业务路由。
- `routers/` 按领域划分（records、timeline、tasks、context、query、process、mood、asr、merge、user、sync、export），每个 router 仅负责请求解析与响应序列化，不直接操作数据库。
- `services/` 封装核心业务逻辑：`processor.py` 实现「未处理记录 → 事件/任务/上下文」的完整处理管线；`llm.py` 统一通过 httpx 调用 Cloudflare Relay（DeepSeek v4-flash），提供 chat/chat_stream/classify/generate_timeline/generate_tasks/generate_context/answer_query/generate_mood/polish_asr_text 等函数；`fuzzy_match.py` 提供任务去重模糊匹配。
- `models.py` 定义 SQLAlchemy ORM（Record、Event、Task、Context、Mood 及三张关联表）；`schemas.py` 用 Pydantic v2 定义请求/响应模型，统一 `from_attributes=True` 以支持 ORM→Pydantic 转换。
- `database.py` 提供异步引擎、会话工厂、`get_db` 依赖注入、用户 ID 和语言提取，以及带白名单校验的迁移脚本。
- `security.py` 实现基于内存滑动窗口的渐进式限流（区分 AI 调用、写操作、读操作三类速率限制）、SQL 注入防护（表名白名单）和用户 ID 格式校验。
- 配置集中于 `config.py`，通过环境变量控制数据库 URL、Relay 地址、TLS 策略、模型选择与温度参数。
